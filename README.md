## 🇨🇳 简体中文

> 探索浩瀚宇宙，分享星辰大海，一起畅聊太空奥秘。

### 📖 项目简介

**Space-Exploration-Post** 是一个以太空探索为主题的社区帖子平台，采用 Grok 风格暗色极简 UI 设计，集成了帖子发布、评论互动、火箭发射时间表等丰富功能。用户可以分享太空相关的想法和图片，关注即将到来的火箭发射，体验宇宙探索的乐趣。

### ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 📝 **帖子系统** | 支持发布图文帖子，热门/最新双标签切换浏览 |
| 💬 **评论互动** | 每篇帖子下方可展开评论区，实时交流 |
| 📌 **置顶帖子** | 管理员可置顶重要帖子，始终显示在最前 |
| ❤️ **点赞收藏** | 一键点赞，记录你喜欢的帖子 |
| 🔗 **分享功能** | 一键复制链接，分享帖子到其他平台 |
| 👤 **用户系统** | 注册/登录，个性化头像与昵称 |
| 🖼️ **图片上传** | 发帖时支持上传图片，图文并茂 |
| 🚀 **火箭发射时间表** | 实时倒计时显示即将发射的火箭，精确到秒 |
| 🏁 **已发射记录** | 发射完成后自动归档，保留最近 20 条记录 |
| 🏛️ **官方机构账号** | NASA、CNSA、SpaceX 等官方账号，专属徽标与权限 |
| 🔐 **权限管理** | 仅官方账号可添加/编辑/删除火箭发射信息 |
| 💓 **心跳保活** | 每 12 小时自动访问 JSONBlob，防止数据过期 |
| 🌌 **太空主题 UI** | Grok 风格暗色界面，星空背景，沉浸式体验 |

### 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| **HTML5** | 页面结构与语义化 |
| **CSS3** | Grok 风格暗色 UI、响应式布局、动画效果 |
| **JavaScript** | 前端逻辑、API 交互、实时倒计时 |
| **JSONBlob** | 云端数据存储（帖子 + 用户分离存储） |
| **GitHub Pages** | 静态网站托管与部署 |

### ⚙️ 配置说明

项目使用 JSONBlob 作为云端数据存储，配置位于 `index.html` 中：

```javascript
// 帖子数据 Blob
const BLOB_ID = 'your-posts-blob-id';

// 用户数据 Blob
const USERS_URL = 'https://api.jsonblob.com/your-users-blob-id';
```

如需使用自己的数据源，请前往 [JSONBlob](https://jsonblob.com/) 创建新的 Blob 并替换上述配置。

### 📦 部署

本项目使用 **GitHub Pages** 部署：

1. Fork 本仓库
2. 进入仓库 **Settings → Pages**
3. 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`
4. 保存后等待构建完成（约 10-15 分钟）
5. 访问 `https://<你的用户名>.github.io/Space-Exploration-Post/`

> 💡 **提示**：GitHub Pages 构建可能存在缓存，更新后可使用 `Ctrl+F5` 强制刷新，或在 URL 后追加 `?v=2` 绕过 CDN 缓存。

## 🇬🇧 English

> Explore the vast universe, share the sea of stars, and discuss the mysteries of space together.

### 📖 About

**Space-Exploration-Post** is a space exploration themed community platform built with a Grok-style dark minimalist UI. It integrates post publishing, comment interaction, rocket launch schedules, and more. Users can share space-related thoughts and images, follow upcoming rocket launches, and experience the joy of cosmic exploration.

### ✨ Key Features

| Feature | Description |
|---------|-------------|
| 📝 **Post System** | Publish text & image posts; switch between Hot/New tabs |
| 💬 **Comments** | Expandable comment section under each post |
| 📌 **Pin Posts** | Admins can pin important posts to the top |
| ❤️ **Likes** | One-click like, track your favorite posts |
| 🔗 **Share** | Copy link with one click to share posts |
| 👤 **User System** | Register / login with custom avatar & nickname |
| 🖼️ **Image Upload** | Upload images when posting |
| 🚀 **Launch Schedule** | Real-time countdown for upcoming rocket launches |
| 🏁 **Launch Archive** | Auto-archived after launch; keeps the 20 most recent |
| 🏛️ **Official Accounts** | NASA, CNSA, SpaceX with exclusive badges & permissions |
| 🔐 **Permission Control** | Only official accounts can manage launch entries |
| 💓 **Heartbeat Keep-alive** | Auto-pings JSONBlob every 12 hours to prevent data expiry |
| 🌌 **Space-themed UI** | Grok-style dark interface with starry background |

### 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **HTML5** | Page structure & semantics |
| **CSS3** | Grok-style dark UI, responsive layout, animations |
| **JavaScript** | Frontend logic, API interaction, real-time countdown |
| **JSONBlob** | Cloud data storage (separate blobs for posts & users) |
| **GitHub Pages** | Static site hosting & deployment |

### ⚙️ Configuration

The project uses JSONBlob for cloud data storage. Configuration is in `index.html`:

```javascript
// Posts data blob
const BLOB_ID = 'your-posts-blob-id';

// Users data blob
const USERS_URL = 'https://api.jsonblob.com/your-users-blob-id';
```

To use your own data source, create new blobs at [JSONBlob](https://jsonblob.com/) and replace the configuration above.

### 📦 Deployment

This project is deployed using **GitHub Pages**:

1. Fork this repository
2. Go to **Settings → Pages**
3. Select **Deploy from a branch**, choose `main` branch and `/ (root)` directory
4. Save and wait for the build to complete (~10-15 minutes)
5. Visit `https://<your-username>.github.io/Space-Exploration-Post/`

> 💡 **Tip**: GitHub Pages may cache content. Use `Ctrl+F5` to force refresh after updates, or append `?v=2` to the URL to bypass CDN cache.
